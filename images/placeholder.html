🔧 如何修改内容 / How to Edit Content

所有文字内容在 index.html 中，每个元素都有 data-en 和 data-cn 属性，分别对应英文和中文。

品牌色在 css/style.css 顶部的 :root 变量中修改。

结构化数据（产品列表、导航菜单等）在 js/config.js 中。

🚀 如何预览 / How to Preview

直接在浏览器中打开 index.html 即可预览。无需服务器。
